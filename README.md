# Система распознавания сообщений от ботов на основе машинного обучения

## Описание
Прототип системы для автоматической классификации текстовых сообщений на категории **«спам»** и **«не спам»** с использованием методов машинного обучения и больших языковых моделей (LLM).


## Цели проекта
- Разработка методики автоматической классификации сообщений
- Сравнение традиционных подходов (TF-IDF + классификаторы) с современными LLM
- Минимизация ложных срабатываний (False Positives) при сохранении высокой полноты обнаружения

## Технологии
- **Python 3.12+**
- **Scikit-learn** (TF-IDF, SVM, Random Forest)
- **Pandas, NumPy** (обработка данных)
- **Matplotlib, Seaborn** (визуализация)
- **LLM**: Qwen3.5-Plus, GigaChat, Deepseek
